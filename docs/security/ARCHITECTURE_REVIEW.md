# Security Gate 1.1 — kontrola bezpečnostní architektury

**Historická Gate1.1 kontrola. Současné pořadí body/admission, cookies, /64 quotas, cache, network a immutable release identity popisují [Remediation report](REMEDIATION_1_REPORT.md) a [current review package](INDEPENDENT_REVIEW_PACKAGE.md). Tato autorská kontrola není independent sign-off.**
2026-10-08. **Lokální evidence autora implementace. Nejde o nezávislé review. Release BLOCKED.** PASS v testu znamená pouze ověřený scénář, ne bezpečnost celé vrstvy. Produkční Cloudflare/VPS/staging důkazy nejsou dostupné. Zdrojové soubory, deployment konfigurace, frontend i AI pipeline zůstaly v tomto kroku beze změny.

## Další invarianty a důkazy

- **Static exposure:** [server.js:assets](../../src/server.js#L10) má pouze 4 frontend URL a 14 přesných PNG. Žádný assets wildcard, directory listing, .env/Git/docs/testy. [security.test.js:L50](../../tests/security.test.js#L50) a [characters.test.js](../../tests/characters.test.js) PASS. .dockerignore a explicitní Docker COPY navíc omezují runtime filesystem; runtime report nedokládá bezpečnost host release directories.
- **Data-only input:** [TextAIWorker.call](../../src/ai/pipeline.js#L10) oddělené system instructions od JSON `untrusted_content`; [validateOutput](../../src/ai/schema.js) schema/evidence/verification; [ai.test.js](../../tests/ai.test.js) injection roles/unsafe output PASS. Není to matematická garance absence prompt injection ani pravdivosti modelu; pravidla-only beta model nepoužívá.
- **No fetch/upload:** [AnalysisPipeline.analyze](../../src/ai/pipeline.js#L75), [server.js](../../src/server.js#L104). URL zpracována jen jako text; [security.test.js:L147](../../tests/security.test.js#L147) skutečný loopback target dostal 0 visits. PDF/image upload/SSRF gates zůstávají [DATA_AND_FEATURE_GATES.md](DATA_AND_FEATURE_GATES.md).
- **Browser rendering:** [public/app.js](../../public/app.js) používá textContent/DOM API pro výstup; [security-browser.js](../../scripts/security-browser.js) skutečný Chromium odmítl vykonání injektovaného HTML-looking summary/signals a ověřil 1440/390/320 bez overflow. Nejde o plný pentest ani kompletní accessibility audit.
- **Health/restart:** [healthcheck.js](../../scripts/healthcheck.js), createServer `/api/health`, SIGTERM/shutdown; [security.test.js:L172](../../tests/security.test.js#L172) drain PASS. `restart: unless-stopped` restartuje ukončený proces, **nikoli automaticky unhealthy kontejner**. Alert/recovery owner a live monitor čekají.

## Závěr pro reviewera

Lokální kódové invarianty mají konkrétní testy, ale zbývají 34 neschválené package nálezy, runtime/native provenance otázky a výše uvedené testovací mezery. Nezjištěna a neprokázána nová P0/P1 vzdálená exploit cesta; to není důkaz její neexistence. Release blokují R00/R03–R06/R13 z [SECURITY_RELEASE_GATE.md](SECURITY_RELEASE_GATE.md). Rozhodnutí o riziku musí být odděleno od autora této kontroly a zaznamenáno externím reviewerem a schvalujícím člověkem.
