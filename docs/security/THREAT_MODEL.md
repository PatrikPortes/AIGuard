# Security Gate 1 — threat model (STRIDE)

Audit: 2026-10-08. Cíl: samostatné Ubuntu 24.04 VPS, 2 vCPU / 4 GB / 40–80 GB, Docker Compose, Cloudflare. Domácí server byl zrušen jako deployment target. VPS ani produkční Tunnel dosud neexistují. Nejde o pentest.

## Skutečná plocha útoku

Native Node 24 HTTP server; statické HTML/CSS/JS bez bundleru či externích frontend závislostí. GET /, /privacy, /app.js, /style.css, 14 explicitních PNG; GET /api/health, GET /api/session, POST /api/analyze. Rules analyzuje pouze text a zápis HTTP(S) URL. Nenavštěvuje URL, nepřijímá soubory, nemá účty, administraci ani sdílené výsledky. AI implementace existuje za serverovým rozhraním, produkční guard ji nyní zakazuje.

Aktiva: soukromý obsah v RAM, správnost doporučení, dostupnost, budoucí AI rozpočet, deployment artefakty, token connectoru, SSH/Cloudflare účty. Anonymní uživatel ani obsah zprávy nejsou důvěryhodní. Session cookie je podepsaná kvóta, nikoli přihlášení nebo důkaz lidskosti.

Hranice: veřejný klient → Cloudflare TLS/WAF → vlastní cloudflared → vlastní Docker bridge → app. App důvěřuje CF-Connecting-IP jen od jediného přesného socket IP connectoru, s jedinou validní hlavičkou. X-Forwarded-For/Host/Proto, X-Real-IP a Forwarded nemění identitu či CSRF origin. Root/Docker správce, connector a Cloudflare zone správce jsou privilegovaní důvěryhodní aktéři; jejich kompromitaci nevyřeší IP allowlist. Na bridge není kryptografická autentizace peeru. Administrátor musí potvrdit edge overwrite hlaviček, nepřítomnost nedůvěryhodných Workers/transformů a Pseudo IPv4 overwrite. Nepřidávat další kontejnery na ingress síť.

STRIDE: S spoofing, T tampering, R repudiation, I information disclosure, D denial of service, E elevation of privilege. Závažnost vyjadřuje potenciální dopad před mitigací, ne potvrzenou exploitovatelnost konkrétního CVE.

## Rozhodnutí a zbytkové riziko

Single VPS je vhodný pro omezenou rules betu po uzavření P0/P1; neslibuje obsluhu 10 000 souběžných lidí. Overload je záměrné omezení, nikoli úspěšná analýza. Procesové kvóty se restartem resetují, cookies lze obnovit a botnet může zablokovat globální kapacitu. Obsah ve V8 RAM nelze spolehlivě kryptograficky vymazat. No-store nenahrazuje kontrolu prohlížeče či screenshotu uživatele. Lokální automatizované testy nenahrazují independent security review, staging edge test ani pentest. Accepted Risk vyžaduje jmenovité schválení člověkem; v tomto auditu žádné nebylo uděleno.
